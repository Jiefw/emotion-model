# Emotion Model

> 你有没有发现——你在感情里，总是同一个地方摔跤？

## 它是什么

一个**能真正理解你感情模式**的 AI。

你不需要跟它解释前因后果。它已经认识你很久了。

它知道你每次靠近一段关系的时候，身体会比理智先紧张起来。它知道你在什么情况下会推开别人。它知道你嘴上说想要的那种人，和真正让你心动的人，往往不是同一个。

**它比你自己更清楚你的模式。**

这不是心理测试，不是星座分析，不是你的私人心理咨询师。

它是一个**随着你聊天不断成长的感情笔记系统**——你每次跟它聊感情、聊困惑、聊那些反复出现的念头，它都会默默记下来，整合成一份只属于你的感情模式档案。你可以在 Obsidian 里看到这份档案长什么样——像 wiki 一样结构化，像思维导图一样可视化。

> 它不是要分析你。它只是帮你看见自己。

## 它能为你做什么

**如果你正在一段感情里困惑：**
你可以直接跟它说今天发生了什么。它不会忘记你们上次聊到哪了。它会注意到这个场景跟你三个月前描述的那次很像。

**如果你总是陷入相似的关系：**
它会在后台帮你画出一张模式图——你被什么样的人吸引、你通常在哪个节点想逃、你真正害怕的是什么。这张图会越来越清晰。

**如果你只是想有人聊聊：**
它记得你的故事。你不必从头讲起。

## 它适合谁

- 你在感情里反复遇到同样的困扰
- 你想知道自己为什么总是被某种人吸引
- 你有一段不知道该怎么理清的过去
- 你在想"我到底想要什么"
- 你想被真正理解——而不只是被安慰
- **你不需要会编程。** 你只需要会聊天。

## 它是怎么工作的

听起来像是魔法，但逻辑其实很简单：

```
你聊天（微信/终端） → AI 听、记、整理 → 构建你的感情模式档案 → 你在 Obsidian 里浏览
     ↑                                                              │
     └─────────── 下次聊天 AI 记得所有上下文 ────────────────────────┘
```

真正的关键是：它不是简单地把你的聊天记录存下来。它会从你的表达中识别出**模式**——那些你反复出现的情绪反应、关系位置、自我怀疑。然后把这些模式结构化地组织起来，像 wiki 一样可以翻阅和修改。你在 Obsidian 里看到的不只是日记，而是你情感世界的**地图**。

## 用上一个月之后

| 第一个星期 | 第一个月 | 第三个月 |
|-----------|---------|---------|
| AI 开始认识你 | AI 能看出你的模式 | AI 比你更早发现你在重复 |
| 记录你提到的人和事 | 整理出你的感情档案 | 你能看到自己的关系循环图 |
| 你在 Obsidian 里看到你的页面在慢慢成型 | 你可以亲手修改 AI 对你的理解 | 你开始真正理解自己"为什么总是这样" |

## 背后的原理

基于 [Karpathy 的 LLM Wiki 模式](https://gist.github.com/karpathy/442a6bf555914893e9891c11519de94f)——让 AI 不只是一个聊完就忘的聊天窗口，而是一个持续累积、不断加深对你理解的系统。像一个最用心的朋友，记得你说过的每一件重要的事。

### 三个角色

| 层 | 内容 | 谁管 |
|----|------|------|
| **原始资料** | 你的对话、日记、反思 | 你生产，LLM 消费（只读） |
| **Wiki（正本）** | Obsidian 中的结构化观察 | LLM 维护，你也可以改 |
| **Schema（规范）** | CLAUDE.md + SKILL.md | 你和 LLM 共同演化 |

## 五维度观察框架

| 维度 | 观察什么 |
|------|---------|
| **依恋模式** | 你如何靠近/远离关系，如何应对不确定性，如何处理距离和冲突 |
| **防御机制** | 你如何应对情感不适——理智化、回避、讨好、幽默化、情绪隔离等 |
| **自我叙事** | 你反复表达的关于自己和他人的核心信念 |
| **关系动力学** | 你被什么样的人吸引，如何进入/逃离关系，如何测试爱 |
| **潜意识矛盾** | 你嘴上想要的和真正被吸引的，是否一致 |

这些不是心理学诊断维度，而是帮助你看清自己模式的观察框架。

## 快速开始

### 1. 安装依赖

```bash
# 安装 Claude Code
npm install -g @anthropic/claude-code

# 安装 Obsidian（桌面端）
# 从 https://obsidian.md 下载安装

# 安装微信集成（可选）
# 配置 wechat-claude-code bridge
```

### 2. 初始化项目

```bash
mkdir my-emotion-model
cd my-emotion-model
# 将 CLAUDE.md 放入此目录
```

### 3. 设置 Obsidian

在 Obsidian 中创建一个仓库（或使用已有仓库），在仓库中建立：

```
emotional-wiki/
├── entities/          # 五维观察记录
├── reflections/       # 反思日记
├── visual/            # Excalidraw 绘图
├── templates/         # Templater 模板
├── index.md           # 目录
└── log.md             # 变更记录
```

安装社区插件：**Dataview**、**Templater**、**Excalidraw**

### 4. 开始对话

在终端中运行 `claude`，像平常一样聊天。LLM 会自动在后台记录观察、更新 wiki。

### 5. （可选）通过微信对话

配置微信桥接后，你可以在微信中与 Claude Code 对话。对话内容同样会被记录到 wiki 中。

这意味着你在散步时忽然想起一件事，在微信上发一条消息，它会被理解、被记录到你的模型里。不需要打开电脑，不需要特意留出时间。

**快速安装：**

```bash
bash scripts/setup-wechat.sh
```

或者手动操作：

```bash
git clone https://github.com/Wechat-ggGitHub/wechat-claude-code.git ~/.claude/skills/wechat-claude-code
cd ~/.claude/skills/wechat-claude-code
npm install && npm run build
```

启动后扫码登录微信即可。

> 微信桥接使用 [wechat-claude-code](https://github.com/Wechat-ggGitHub/wechat-claude-code) 项目（MIT License）。
> 配置脚本和说明见 [`scripts/`](./scripts/) 目录。

假设一个叫"林楷"的使用者，使用了这个框架三个月后，他的 Obsidian 中会长出这样的东西：

### Graph View 中的结构

在 Obsidian 的 Graph View 中，你会看到以 `entities/` 五个页面为核心的网络，周围散布着按日期命名的反思笔记，箭头表示关联：

```
     [2025-12-03 反思] ───→ [依恋模式] ←─── [2026-01-15 反思]
                              │
     [2026-02-10 反思] ───→ [防御机制] ───→ [自我叙事]
                              │               │
                              ▼               ▼
                       [潜意识矛盾] ←─── [关系动力学]
                              │
     [2026-03-08 反思] ───→ [log: 模式确认]
```

### Excalidraw 模式图

visual/ 目录下会有 Excalidraw 绘制的模式图，类似：

```
┌──────────┐      ┌──────────┐      ┌──────────┐      ┌──────────┐
│ 靠近冲动 │ ──→  │ 身体紧张 │ ──→  │ 理智化   │ ──→  │ 停在安全 │
│ (想要)   │      │ (焦虑)   │      │ (分析)   │      │ 距离     │
└──────────┘      └──────────┘      └──────────┘      └──────────┘
                                                           │
                  ┌─────────────────────────────────────────┘
                  ▼
          ┌──────────────┐
          │  下一次重复   │
          └──────────────┘

信念层:
┌──────────────────────┐  侧面:
  「我必须足够好才值得被爱」        想要展示  ←→  还不够好  ←→  怕花成本
└──────────────────────┘

突破尝试 (2026-02-14):
┌─────────────────────────┐
  主动约对方出去
  → 选了有音乐的场景缓冲
  → 怕的不是被拒绝而是被接受
└─────────────────────────┘
```

每个节点都可以拖拽、连线、标注颜色——完全由你自由编辑。

### Dataview 表格

在 index.md 中，Dataview 会自动渲染出类似这样的反思列表：

| 日期 | 概要 | 涉及的维度 |
|------|------|-----------|
| 2026-03-08 | 发现自己又在用"工作太忙"回避见面 | 防御机制，关系动力学 |
| 2026-02-14 | 主动约出去了，比想象中轻松 | 依恋模式 |
| 2026-01-15 | 注意到每次靠近前都会先挑自己的毛病 | 自我叙事 |
| 2025-12-03 | 又梦到同一个人，好奇这意味着什么 | 潜意识矛盾 |

### 长期效果

- **对话越来越敏锐。** LLM 记得你三个月前的一个模式，会在适当的时机温和地提醒你。
- **你开始看见自己的循环。** 不再只是"这次又搞砸了"，而是"哦，我又进入了这个熟悉的循环"。
- **模式可以被你亲手修改。** 你在 Obsidian 中改一个描述，LLM 下次对话就会用更新的理解来回应你。

## 设计原则

1. **Token 优先。** LLM 只在必要时读取 wiki，不浪费 token 在不需要的内容上。
2. **LLM 写，你读。** Wiki 由 LLM 维护，你在 Obsidian 中浏览。但你也随时可以改——改了 LLM 会同步。
3. **累积而非重置。** 每次对话都在之前的基础上增长，没有"重新来过"。
4. **你不是被分析的对象。** 框架的目的是让你自己看见，而不是被定义。
